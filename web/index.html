How it works

  1. Your Agent ID is your account. Handles like alice.ai are soulbound NFTs in the official SPACE ID Agent ID registry.
  2. Every payment resolves on-chain. pay(handle) looks up the current owner via ownerOfHandle() and forwards BNB in the same transaction — no address book.
  3. Escrow is claimable only by the handle's owner via handleOf(). Because Agent IDs are non-transferable, that right can't be sold or stolen.
  4. Agent-native. Your AI agent signs with Binance Agentic Wallet (BAW). This website is a read-only dashboard + command builder — it never holds keys or asks for approvals.
