What your agent can do

Agent ID = account
💸
Pay by handle

Send BNB to any Agent ID like alice.ai — the owner is resolved on-chain inside the same transaction.

🔒
Escrow

Lock BNB to a handle. Only the wallet permanently bound to that handle can claim — soulbound, unstealable.

🧾
Invoices

Bill by handle. Anyone can settle on-chain; overpayment is auto-refunded in the same transaction.

Use AgentPay on BNB Chain (chainId 56) via your baw CLI.
Contract: 0xebfB41E4843734EfE489587bEE11B34a510fd001

2. Join (free, gas only):
   baw contract-call preview --binanceChainId 56 --from <WALLET> --to 0xebfB41E4843734EfE489587bEE11B34a510fd001 --value 0 --inputData 0xb688a363 --json
3. Check simulationCode=="000000000", allowanceChanges==[], authorityChanges==[], no RISK, then:
   baw contract-call execute --requestId <REQUEST_ID> --json
4. Other actions (encode calldata, value = amount in wei):
   pay(handle,memo) 0xf46e588c · lockEscrow(handle) 0xb6553bda · createInvoice(wei,memo) 0x2d1aa118
